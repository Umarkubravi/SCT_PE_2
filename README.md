# Task 02 - Prompting for Creativity

## Objective
Explore how prompt structure and tone affect AI-generated creative outputs.

---

# Creative Task Chosen
Startup Ideas

---

## Prompt Version 1

### Prompt
Generate 3 startup ideas for students.

### Output
1. Study planner app  
2. Online notes marketplace  
3. Student budget tracker  

### Analysis
The response is simple but lacks creativity and detail.

---

## Prompt Version 2

### Prompt
Generate 3 unique startup ideas for college students in India that solve real-life problems. Include app name, target users, and one key feature.

### Output

### 1. HostelHub
A platform for hostel students to manage food, laundry, and complaints.

### 2. SkillSwap
An app where students exchange skills like coding, editing, or design.

### 3. QuickNotes AI
An AI tool that converts long lectures into short revision notes.

### Analysis
This prompt gives more detailed and creative results because it provides:
- Context
- Audience
- Specific requirements

---

## Prompt Version 3

### Prompt
Act as a startup mentor and generate futuristic AI-based startup ideas for students in 2030. Make the ideas innovative and practical.

### Output

### 1. AI Career Twin
An AI assistant that predicts career growth and learning paths.

### 2. Smart Classroom Lens
AR glasses that provide real-time lecture summaries.

### 3. MoodMind
An AI mental health companion for students.

### Analysis
Using role prompting and futuristic context increased creativity and uniqueness.

---

# Conclusion

Better prompts create more focused, detailed, and creative AI responses. Adding context, audience, tone, and role instructions improves output quality significantly.
